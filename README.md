# B2B Trade Hub

Адаптивный веб-интерфейс B2B-площадки для торговли между компаниями в современном Apple-like стиле.

## Возможности
- Два типа объявлений: `Компания продает` и `Компания покупает`
- Лента сделок с карточками компаний, ценой, объемом и городом
- Фильтры по типу сделки, категории и поиску
- Быстрые кнопки для режима продажи и закупки
- Публикация нового объявления через модальное окно с несколькими лотами (позиция, количество, max цена)
- Дашборд с ключевыми метриками (объявления, проверенные компании, средний чек)
- Сохранение объявлений в `localStorage`
- Полная адаптация под мобильные устройства

## Запуск
1. Откройте `index.html` в браузере
2. Или поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

Далее откройте `http://localhost:8000`.
